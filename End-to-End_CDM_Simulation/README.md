# End-to-End CDM Simulation – Phase III Randomized, Double-Blind Clinical Trial

## Overview

This is an end-to-end Clinical Data Management (CDM) simulation based on a fictional Phase III randomized, double-blind, placebo-controlled clinical trial in Type 2 Diabetes Mellitus.

The project demonstrates the CDM workflow from protocol review and eCRF design through simulated EDC activities, data cleaning, medical coding, reconciliation, database freeze, SQL validation and Power BI reporting.

> **Disclaimer:** This is a portfolio simulation created for learning and demonstration purposes. It is not professional clinical-trial experience and contains no real patient, sponsor, or confidential clinical-trial data.

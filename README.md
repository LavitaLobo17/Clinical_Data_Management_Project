# Clinical Data Management Project

## Overview
This project demonstrates Clinical Data Management (CDM) workflows using Microsoft Excel.

## Features
- Raw clinical dataset creation
- Validation checks
- Duplicate subject identification
- Future date validation
- Blood pressure range checks
- Missing value identification
- Query tracking system
- Pivot table analysis
- Dashboard visualization

## Tools Used
- Microsoft Excel
- Pivot Tables
- Conditional Formatting
- Data Validation
- Charts & Dashboards

## Key Learnings
- Clinical data cleaning
- Query management
- Data discrepancy analysis
- Clinical trial data handling
